# Intelligent μWave Energy Center

서울시립대학교 전자전기컴퓨터공학과 **지능형 전파-에너지 연구센터(IUEC)** 홈페이지.

> **개발 중입니다.** 아직 사이트가 만들어지기 전이라 실행할 수 있는 것이 없습니다.
> 진행 상황은 [Issues](https://github.com/UOS-IUEC/homepage/issues)와 [Milestones](https://github.com/UOS-IUEC/homepage/milestones)에서 볼 수 있습니다.

## 기술 스택

Next.js (App Router) · TypeScript · Tailwind CSS

논문·구성원 같은 콘텐츠는 코드가 아니라 `content/` 폴더의 JSON 파일로 관리합니다.
구조가 만들어지면 이 문서에 **콘텐츠 수정법**을 정리할 예정입니다 (#19).
